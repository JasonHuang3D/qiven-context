## Product objective

Build an industrial-gas enterprise management/operating system covering day-to-day operations, personnel, customer development, tasks, business workflows, and node-level traceability.

## Durable boundaries

- The gas product is not required to consume the native C++ Foundation/Math/Geometry stack merely to be part of Qiven.
- Reuse should occur where semantics are genuinely shared: AI gateway patterns, protocol/data contracts, workflow, identity/audit, and business infrastructure.
- Native C++ components are introduced only when a concrete requirement such as hardware integration, device-side processing, simulation, or performance makes them the right tool.
- Product architecture should optimize for business-system correctness, traceability, deployment, and iteration speed rather than language uniformity.
