# Separate Host authority-kernel acceptance from production integration

## Context

The original Host Batch 000 checklist required production DCR, filesystem, Git, and process no-bypass proof before accepted Runtime and DCR production baselines or a canonical Host remote existed. The worker correctly stopped: those facts could not be truthfully proved at the Host authority-kernel layer.

## Decision

Host Phase 0 is split into two ownership-aligned gates. Batch 000 accepts the Host Authority Kernel itself: singleton, lease, fencing, sequencing, idempotency, quarantine, reconciliation, durable state, bounded journal, protected-operation gate, and real owner-local IPC. Batch 001 integrates accepted Runtime and DCR production paths and proves that production mutation cannot bypass Host.

Validation architecture follows semantic ownership just like code. A lower-layer batch proves only facts available at that layer. Future dependencies or adapters must never be invented merely to turn an acceptance checklist green.

Batch 000 acceptance does not re-enable mutating DCR or remote AI execution. That remains suspended until Batch 001 production authority integration passes.

## Alternatives Considered

- Keep the original all-in-one gate. Rejected because it required evidence from nonexistent production layers.
- Create Host-local stand-ins for Runtime and DCR. Rejected because ADR-0024 forbids duplicated or fictional ownership.
- Weaken the no-bypass requirement. Rejected; the requirement remains mandatory at Batch 001, where it can be proved truthfully.

## Consequences

Authority-kernel implementation can proceed independently and receive precise acceptance. Production integration remains explicitly unproven and fail-closed until its own gate passes.

## Revisit Conditions

Revisit the split only if accepted production baselines make both layers inseparable without weakening semantic ownership or test truthfulness.

## Provenance

Recorded after the 2026-09-16 worker reconciliation established that Runtime lacked a Git baseline, DCR Windows lacked a production baseline, and Host lacked a canonical remote.
