# Consolidate all legacy surfaces into the legacy/ museum; .generated-temp is the only generated location

## Context

ADR-0040/0041 sealed the kernel and disarmed its executables, but the
Context v2 era (2026-09-14) had its own legacy-ized surfaces left in
their original locations: the frozen event ledger (`ledger/events/`),
deprecated evidence placeholder buckets, historical Chat handoffs
(`sessions/legacy/`), retrieval benchmarks, and a `generated/` output
convention predating `.generated-temp/`. The owner directed one more
cleanup round at museum grade, and a hard rule for generated
directories.

## Decision

1. Everything legacy lives under `legacy/` (and `decisions/legacy/`
   for archived ADRs): the moves are `ledger/events` ->
   `legacy/ledger/events`, `evidence/{ci,handoffs,research}` ->
   `legacy/evidence/...`, `sessions/legacy` -> `legacy/sessions`,
   `benchmarks/` -> `legacy/benchmarks/`, and the former generated README moved to
   `legacy/generated/README.md`. The validator's required paths, frozen-ledger
   baseline, deprecated-bucket checks and BOOTSTRAP checks now point at
   the museum locations with unchanged semantics (no new museum writes,
   no new ledger events).
2. **`.generated-temp/` is the only permitted generated-artifact
   location** in the repository tree. A plain `generated/` directory is
   a validation error. The old gitignore exception for the
   the former generated README is removed.
3. Incidental loss, disclosed: the untracked K4 handoff artifacts under
   `generated/k4-handoff/` (3.2 MB acceptance outputs) were destroyed
   during the move when a chained command failed on their ignored
   status. Their full identities are preserved in
   `evidence/audits/context-k4-handoff-acceptance-2026-09-18.md`
   (snapshot `sha256:34829abf...`, handoff `sha256:22654511...`), and
   they are reproducible from the exact candidates via the museumed
   producer text. No tracked content was lost.

## Alternatives Considered

Leaving v2 surfaces in place with labels (rejected: not museum grade;
the owner's standard is one museum, no zombies); deleting instead of
moving (rejected: history preserved); allowing both generated
directories (rejected: the rule exists to prevent exactly this drift).

## Consequences

The repository tree has exactly one legacy root and exactly one
generated location. Cold boot reads the museum only as history. The
validator enforces both properties mechanically.

## Revisit Conditions

Only by a new accepted ADR (for example a Runtime-era artifact-handoff
implementation needing a new output location — which would use
`.generated-temp/` anyway).

## Provenance

Owner-directed cleanup round 2026-09-21, immediately after ADR-0041.
