# Archived Decisions

ADR bodies whose accepted content materially conflicts with later
canonical reality are NOT edited in place (owner direction 2026-09-21):
an ADR is historical evidence of how the project reasoned at its time.
Instead the conflicting ADR is moved here unchanged (apart from
lifecycle bookkeeping: status, superseded_by, updated_at, and an
archival banner), its index entry points at the archived location, and
a new ADR records the replacement decision with full provenance.

Files here never participate in active-truth retrieval except as
history; `status: superseded` carries the lifecycle.
