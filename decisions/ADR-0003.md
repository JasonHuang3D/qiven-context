# Keep semantic source data simple and derived retrieval replaceable

## Context
Qiven project cognition must survive individual model sessions and remain auditable.

## Decision
Phase 0 canonical storage uses Markdown, YAML, JSONL, JSON Schema, and Git. SQLite, vector databases, embeddings, and MCP are deferred derived systems.

## Alternatives Considered
Making a database, embeddings, or a service canonical in Phase 0.

## Consequences
Source data remains inspectable and derived retrieval can be rebuilt or replaced.

## Revisit Conditions
Revisit if cold-boot acceptance or operational experience demonstrates the model is insufficient.
