# Externalize Qiven project cognition from LLM sessions

## Context
Qiven project cognition must survive individual model sessions and remain auditable.

## Decision
qiven-context becomes persistent project cognition; model/session memory is not authoritative; evidence, ledger, canonical knowledge, and derived working context are separate layers; storage is conservative and retrieval is selective.

## Alternatives Considered
Keeping cognition in model sessions; using a transcript dump.

## Consequences
Durable cold boots become possible; curation and validation become ongoing responsibilities.

## Revisit Conditions
Revisit if cold-boot acceptance or operational experience demonstrates the model is insufficient.
