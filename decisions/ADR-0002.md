# Use question-scoped authority instead of a global source-precedence chain

## Context
Qiven project cognition must survive individual model sessions and remain auditable.

## Decision
Authority depends on the question. Live Git, ADRs, CI evidence, active work, and obligations answer different classes of questions. Conflicts are surfaced, not silently resolved.

## Alternatives Considered
One global source-precedence chain.

## Consequences
Consumers must identify the question class and report inconsistencies.

## Revisit Conditions
Revisit if cold-boot acceptance or operational experience demonstrates the model is insufficient.
