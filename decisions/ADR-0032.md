# Validate Context Python batches directly in the agent runtime

## Context
Context's portable Python semantics can be executed directly by jason-brother.
Requiring an additional JasonPC relay for the same properties duplicates evidence
without establishing a new platform-specific property.

## Decision
Accept the scoped validation authority and batch cadence in
`collaboration/context-validation.md`. jason-brother may implement, validate,
review and merge exact Context Python/source-contract candidates in the agent
runtime, without redundant JasonPC validation. R1 C01-C06 is authorized as one
coherent implementation batch after the separately accepted C01 checkpoint.

## Alternatives Considered
Continue mandatory JasonPC validation for every portable Context change; remove
platform-specific validation for every Qiven repository. Neither matches the
owner's scoped authorization.

## Consequences
Evidence must identify candidate source, environment and covered properties.
Windows/native/machine-dependent behavior still needs its relevant environment.
Host/DCR remote mutation restrictions remain active. Context evaluation never
substitutes for execution authorization.

## Revisit Conditions
Revisit when a Context change depends on Windows behavior, unavailable dependencies,
real model ranking or performance properties not established by the agent runtime.

Explicit project-owner instruction in the current session on 2026-09-17.
