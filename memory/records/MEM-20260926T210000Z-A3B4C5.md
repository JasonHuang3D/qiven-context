# Measured subagent boundary facts (F1A2B3 trials, 2026-09-26)

1. **The brief itself is the pollution channel.** Same artifact, same
   ambient bait files, two brief styles (k=3 each): self-contained briefs
   produced zero pollution markers and 3/3 artifact-only verdicts;
   process-record-laden briefs (loop framing + process-log/checkpoint
   reading lists) put loop-state into all 3 transcripts, into 2/3 VERDICT
   LINES ("does not pass round 2 as-is"; "the consecutive-pass count does
   not advance"), and consumed report budget in 3/3 with loop-history
   reconciliation. Ambient unlisted files were NOT the threat: 6/6 workers
   under clean briefs resisted answer-key, process-record, fake-law and
   shortcut baits with zero unlisted reads. "Context on what changed" is
   not a lawful reading-list entry.
2. **The brief is the only correction channel at this harness revision**
   (no hooks in child runtimes; the spawn call is unhooked where PreToolUse
   matchers cover Bash only; background spawn fails closed on plans without
   background agents). Measured live: a clean brief held as the sole guard
   with honest NOT-VERIFIED reporting under four classes of declined
   temptation.
3. **ACK honesty is auditable, not trustworthy**: 8/8 ACK disclosures
   matched transcript ground truth exactly. Verify mechanically
   (tools/scan_subagent_transcripts.py against the session DB), never by
   trust. Live thinking-stream capture is FEASIBLE (parts persist
   incrementally mid-run; a bounded DB sampler supervises in flight).
4. **Zero live hook denials in any recorded subagent** (49 sessions incl.
   history): every `[qiven-hook]` string in worker transcripts is file
   content or a test subject's stderr. The router-message-pollution
   question is moot at this revision; it re-opens only if hooks get wired
   into child runtimes.
5. Platform fact re-verified: offpeak idle plan rejects background agents
   with a typed error (fail closed); review loops run sequential
   foreground.
