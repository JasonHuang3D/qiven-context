# Exact remote review is required even after a passing worker handoff

The Batch 001 worker handoff reported the Windows wrapper validations as passing, but exact remote review found `tools/validate.cmd`, `tools/test.cmd`, and `tools/verify-live-state.cmd` using an `if ... & exit /b 2` form in which the `exit` command is not scoped by the `if` condition. That makes the wrappers terminate before invoking Python when written in that form.

A structured worker handoff is useful evidence, but it is not proof of the committed remote state. Exact remote delta review and independent validation remain mandatory before CTO PASS.
