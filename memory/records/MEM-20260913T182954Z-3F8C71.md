# Math Batch 007 established compact Vec2 Vec3 Vec4 core with exact equality and same-scalar arithmetic

At the pinned Math main commit, the public implemented surface consists of `floating_scalar`, `Vec2`, `Vec3`, `Vec4`, aliases for `f32`/`f64`, exact equality, indexing, unary plus/minus, vector addition/subtraction, same-scalar multiply/divide, and assertion-based division-by-zero preconditions.

The tests require aggregate, standard-layout, trivially-copyable values with exact scalar alignment and no hidden padding. They also reject implicit `float`/`double` vector conversion and mixed-scalar multiplication.

Vector algorithms such as dot, cross, length, normalization, distance, and near-comparison are not part of Batch 007 and remain future work.
