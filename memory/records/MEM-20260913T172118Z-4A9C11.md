# Windows write failures require layered permission diagnosis

On this Windows host, `qiven-context` writes failed while files in the repository tree carried read-only attributes. Clearing the read-only attribute recursively allowed jason-worker to write and complete the task.

Do not generalize the Explorer folder Read-only checkbox into an NTFS ACL rule. Future write failures must distinguish at least file attributes, NTFS ACLs, agent or sandbox policy, and process/file locks before assigning a cause.
