# Untested wire contracts collapse into undifferentiated denials

MVP-4 H1 trial 3 (deny-116 with a healthy host): the serve loop served
exactly one frame per connection while the hook client sent Hello + HookEvent
on one connection; every local probe used the single-frame client that
matched the server's accident, no test sent two frames on one connection,
and admission rejection had no reply surface — so no-listener, admission,
version-skew, secret-skew, timeout, and a destroyed pipe all surfaced as the
same "no reply from host" 116.

Law: an IPC/protocol boundary is not proven until the REAL client shape runs
against the REAL server over the REAL transport in a test that would fail
under the prior defective model. Denial vocabularies at fail-closed
boundaries must be disjoint and diagnosable per failure cause — one
undifferentiated "unavailable" code turns every future incident into an
archaeology dig. A guard that is constructed but never invoked (ReplayGuard)
and a comment describing behavior the code does not perform are defects, not
documentation.
