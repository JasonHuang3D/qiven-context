# Operator gate odyssey (2026-09-19)

Recording the commit identity attribution convention required four gate
invocations and roughly ten minutes of owner-visible wall time for a
five-file prose transaction. Root causes, classified:

- **Operator ergonomics (2).** The CLI shape was not discoverable from its
  error messages: three failed invocations (subcommand required; global flag
  placement; gate takes no name argument). `--json` emits one unbounded line
  whose buffered suite logs were lost when piped, forcing reruns to see
  failures.
- **Output-view misuse (1, agent-side).** Machine JSON was piped through
  `tail` instead of using the human view or capturing whole output.
- **Environment boundary (1).** A Git Bash `/tmp/...` path is invisible to
  Windows Python; the rerun needed a Windows path.
- **Authoring-time knowledge gaps (2).** Memory-record `epistemic.basis`
  accepts a different enum than `sources[].type` (and than ADR source types);
  the current session checkpoint must contain exact literal phrases
  ("Qiven-v2 through Qiven-v5", "Do not synthesize them",
  "ContextView<ChatGPT, Jason>") previously discoverable only by failing the
  cold-boot contract test one assert at a time.

The gates themselves worked correctly: every failure was a true violation
catch, and no contract semantic defect was found. Fixes applied the same day:
the checkpoint contract test now reports all missing headings and phrases in
one failure; the `context-docs` scoped gate exists for record-surface
iteration; the view workflow records gate-invocation discipline
(`MEM-20260919T121032Z-C5D8A1`); the upstream operator ergonomics work is
tracked in `OBL-20260919T121032Z-A9F4D7`.
