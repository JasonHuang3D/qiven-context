# Bind transport-session dispatch and retirement inside one Host lifecycle authority boundary

A Host-owned connection session is not merely metadata passed between transport and authority. Dispatch admission and connection close/retirement form one lifecycle boundary: a frame that was read before close must not be able to obtain authority after its transport session has been retired, and a successful Acquire must become visible to close before slot reuse can occur.

For the Batch 000 dispatcher, derive `BrokerSessionId` from the concrete transport slot and serialize dispatcher dispatch/close lifecycle work conservatively. If future performance requires relaxing global serialization, preserve the same per-session ordering invariant with an explicit stronger mechanism rather than returning to caller-supplied session identity or an implicit race-sensitive convention.
