# Attribution-format rewrite of 2026-09-19

The commit identity convention initially placed the `role:`/`LLM:` block ahead
of the conventional subject, which reduced every commit listing (`git log
--oneline`, Forge views) to the role line instead of the engineering summary.
The owner directed the block to move to the trailer position and the affected
published messages to be corrected.

Fourteen commits across three repositories were rebuilt with `git commit-tree`
plumbing: same tree objects, same parents (remapped), same author/committer
dates, new messages with the attribution block as the trailer. `git diff
<old_head> <new_head>` is empty for every repository — file content is
bit-identical; only messages and therefore SHAs changed. Mains were
force-pushed with `--force-with-lease` under the owner's explicit direction.
GitHub PR records (#24/#25/#26 on qiven-context, #1/#2 on qiven-context-draft,
#2 on qiven-devkit) keep their pre-rewrite SHAs as historical evidence; their
mergeCommit links are stale by construction.
