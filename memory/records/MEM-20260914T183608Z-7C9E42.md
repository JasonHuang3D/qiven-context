# Qiven remote cognition transport must be coarse-grained and explicitly invoked

Normal Chat can reach the authorized JasonPC through the published Remote Desktop Commander plugin, but the observed end-to-end tool call was roughly twenty seconds while local work was sub-second and the target HTTP path was roughly sub-second to one second. Therefore the Phase 1 Qiven cognition path must use explicit per-turn `@qiven` invocation and one coarse-grained local runtime call rather than a chatty sequence of remote filesystem/process operations.

Automatic Skill routing is not trusted, concurrent Qiven turns are not yet accepted, and preflight failure must fail closed. The intended stable boundary is one local `qiven.context.prepare(query, previous_lease?)` operation returning a machine-readable Context Pack plus Context Lease.
