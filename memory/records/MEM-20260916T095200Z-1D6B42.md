# Human-facing Windows batch entrypoints must preserve terminal outcome on direct launch

The observed failure remains valid: a transient Windows console can disappear before the project owner sees the terminal result. The earlier conclusion was too narrow, however, because it promoted `.cmd/.bat` pause behavior into the primary human-interface architecture.

This record is superseded by `MEM-20260916T102500Z-4F7A21`. Current Qiven semantics place human-facing local orchestration in Qiven Operator. Platform launchers must preserve human observability where needed, but `.cmd`, `pause`, PowerShell, POSIX shell, or Python are subordinate implementation details rather than the canonical workflow contract.
