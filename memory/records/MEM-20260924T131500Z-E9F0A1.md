# Public-repo information hygiene is a law, not a preference

All nine qiven repositories are public. A clean secrets scan is NOT a
clean bill: what accumulated instead is targeted-attack reconnaissance
material - the OS username (potentially an external identifier),
user-profile paths, fixed workspace/install roots, the VPN client
identity, split-routing/geo posture, a software inventory with
versions, local proxy endpoints, and machine schedule timestamps. None
is an attack alone; together they are spear-phishing material,
post-exploitation efficiency (which files mediate command execution),
and unattended-window targeting. They also rot: machine literals are
dead info to every other environment. The law
(collaboration/public-repo-information-hygiene.md, 2026-09-24): canonical
records carry placeholder CATEGORIES with live-resolution procedures;
the local authorized agent resolves them at use time; evidence may be
redacted transparently with a dated note; git history is never
rewritten - the history residual is a recorded owner decision
(public-accept vs private). Review enforces it at every PR that
touches records, views, or state.
