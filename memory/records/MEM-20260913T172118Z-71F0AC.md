# qiven-context must not self-pin its live main SHA inside canonical state

Do not attempt to store qiven-context's own current main commit SHA as a live self-reference inside the same canonical repository state that contributes to future commits. Updating the stored value changes repository content and therefore changes the resulting commit identity again.

Record important qiven-context commits as historical evidence after they exist, and verify the current qiven-context head externally when needed. `state/repositories.yaml` therefore tracks external repositories only.
