# Treat high-level Chat-side GitHub contents mutation as unsafe for critical writes until requalified

During Context v2 canonical-merge closeout, Chat repeatedly invoked a high-level GitHub contents write while intending a different repository operation. The connector executed the invoked action; current evidence therefore establishes an assistant/tool action-selection failure but does not establish a GitHub backend defect.

Until an isolated requalification proves the mapping from intended operation to invoked action, do not use high-level Chat-side GitHub contents mutation for canonical merges or other critical writes. Read-only GitHub connector use remains valid. Prefer a human-visible local Git orchestration path; use low-level Git object/ref mutation only when repository, exact refs, trees, parents, and ref-update semantics are explicitly bound and reviewed.
