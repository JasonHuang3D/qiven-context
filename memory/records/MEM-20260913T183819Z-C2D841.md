# Current Qiven product roadmap stages CAD, industrial-gas management, robotics simulation, then deeper native physics

The current long-term product sequence is:

1. CAD/floor-plan to semantic 3D;
2. industrial-gas enterprise management/operating system;
3. robotics/simulation, initially in the class of a MuJoCo-like simulator but intended to grow beyond a clone;
4. deeper Qiven-native physics when product and simulator requirements justify owning more of the physics stack.

This is a roadmap fact, not evidence that all repositories or implementations already exist. The near-term execution queue remains qiven-context completion, Foundation Devkit reconciliation/adoption, and Math Batch 008 before these larger product tracks resume.
