# Agent-invoked commands: timeout always, heartbeat discriminates, no modals

Adjudication of the owner's 2026-09-21 direction (CI was one instance of a
general problem):

1. Every LLM-invoked command carries an explicit invoker-side timeout; no
   unbounded waits. Budgets are sized from evidence (gate receipts carry
   per-task durations) and grown by explicit re-invocation, not by waiting.
2. Timeout is a classification event: record state and logs, then either
   one justified larger-budget re-invocation or investigation. Repeated
   timeouts escalate.
3. Heartbeat answers "alive or hung?" (apparent hang vs healthy long
   work); it never removes the timeout ceiling — liveness is not
   termination, a livelock still beats. With heartbeat, extending the
   budget deliberately is correct; with silence, read logs first.
4. Qiven executables in automated contexts must never block on OS modal UI;
   abort paths terminate. The modal CRT abort incident is the precedent.
