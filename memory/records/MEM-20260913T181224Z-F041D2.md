# Foundation Phase I surface is a compact C++20 static library with explicit low-level primitives

At the verified Phase I pin `f1880847e046425c7f3f3cad22a07d0008aad359`, Foundation builds as the C++20 static target `qiven-foundation` with alias `qiven::foundation`. Public C++ symbols use the `qiven::` root rather than a `qiven::foundation` namespace.

The public surface at that pin includes platform/compiler/config/contracts/types primitives; alignment and checked arithmetic/integer/span helpers; bounded byte cursor/writer and endian conversion; and the memory layer `AllocatorRef`, `Layout`, `LinearArena`, `SystemAllocator`, `OwnedAllocation`, `OwnedObject<T>`, and `OwnedArray<T>`.

This record describes the verified Phase I pin, not a promise that the public API is stable. The repository architecture explicitly remains pre-1.0 and source APIs may evolve under the accepted Foundation laws.
