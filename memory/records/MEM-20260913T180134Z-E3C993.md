# Recurring workflow ambiguity should be codified or automated rather than left to session memory

When a collaboration failure, ambiguous rule, or repeated manual reminder reveals a stable engineering expectation, the preferred response is to update the protocol or automate the check rather than rely on the current model session to remember it next time.

This lesson is one reason Qiven moved branch authority, validation profiles, blocker semantics, batch stop rules, and handoff structure into committed engineering documents. `qiven-context` extends the same principle to cross-session project cognition.
