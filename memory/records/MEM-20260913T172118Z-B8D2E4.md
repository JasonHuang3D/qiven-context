# GitHub plugin authorization does not imply private-repository installation access

A connected or authorized GitHub plugin was sufficient for public-repository access but did not expose the private `qiven-context` repository. Private access became available after the ChatGPT Codex Connector GitHub App was installed on the owning GitHub account with repository access.

Treat plugin connection, user authorization, GitHub App installation, and repository grant as distinct capability states. A future cold boot must verify actual repository accessibility instead of inferring it from a connected-plugin indicator.
