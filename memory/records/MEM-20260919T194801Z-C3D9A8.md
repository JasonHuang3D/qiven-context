# Overnight unattended mode

An owner-opened overnight window is an explicitly authorized unattended
continuation. Inside the window an agent implements, documents, runs local
gates and commits locally on authorized task branches; it never pushes,
opens PRs or merges. Merge-class H2 is not waived - it is DEFERRED to the
owner's batch review at window close, one H2 per branch. A workspace log
records work, evidence and skips; any process unresponsive for more than
five minutes is skipped and logged; no gate is weakened to keep the window
moving.

unattended mode".
