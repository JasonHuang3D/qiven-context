# Math scalar vocabulary is intentionally float and double only until concrete integration requires more

The public `floating_scalar` concept accepts exactly unqualified `float` and `double`. It excludes `long double`, integral types, `bool`, and cv-qualified scalar forms.

The boundary is intentionally narrow rather than a generic numeric customization framework. CAD, geometry, robotics, and initially physics normally use `double`; rendering/GPU boundaries convert explicitly to `float`.

Broadening this vocabulary requires a concrete units or numeric-integration demand rather than speculative generality.
