# Place acceptance gates at the earliest architecture layer where they can be truthfully proven

Validation architecture follows semantic ownership just like code. A lower-layer batch proves only facts available at that layer. If proof requires a future dependency or adapter, move the gate to the integration layer; never invent the missing layer merely to make a checklist green.
