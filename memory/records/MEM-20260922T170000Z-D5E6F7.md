# Piping a gate through a text filter masks its exit code

The P-53 masking class has a shell-level instance: `gate | tail` (or any
text filter) returns the FILTER's exit code, so `gate | tail && publish`
publishes even when the gate failed. The 2026-09-22 correction pattern:

1. Never place a gate (or any fail-fast validator) left of a pipe when
   the chain gates on its exit code.
2. When output trimming is needed, capture the exit code first:
   `python tools/qiven.py gate > out.txt 2>&1; ec=$?; tail out.txt; [
   $ec -eq 0 ] && ...` — or run the gate bare and re-run with --verbose
   only on failure.
3. The merge-proof receipt discipline caught the defect class once
   before (v15, PR #12 RCA-4 swallowed merge output); exit codes are
   evidence exactly like merge states — verify them explicitly.
