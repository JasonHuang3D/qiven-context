# Supervised local agents run operator gates through the human view

Running a Qiven Operator gate on JasonPC is, for practical purposes, the same
act whether the consumer is the owner or a supervised local agent: the human
view (`--verbose`: staged `[ RUN]`/`[ OK ]` markers, heartbeats, buffered-log
summaries) serves both. Machine JSON (`--json`) is a single-line blob whose
buffered suite logs become unrecoverable the moment it is piped through
`tail`/`head`/text filters; in a live session it must either be avoided in
favor of the human view, or captured whole to a file and parsed from that file.

Operator CLI shape (discover with `--help` before invoking): subcommands are
`info`, `gate`, `run`, `ci`; `gate [name]` takes an optional positional gate
name defaulting to the configured default gate (`--name` remains as an alias) —
at the time of the odyssey it took no argument, which was one of the friction
sources; `run <task-name>...` executes one or more tasks. Global flags are
accepted before and after the subcommand. In `--json` mode a gate whose
buffered output exceeds the spill threshold writes the full payload to a
durable file under the OS temp dir and prints a compact summary carrying
`log_file`; smaller outputs remain inline. Correction 2026-09-19: the operator
ergonomics roll (OBL-20260919T121032Z-A9F4D7) changed the CLI shape recorded
above from the version observed during the odyssey.

Gate selection: docs/memory/session/view-only transactions may iterate with
the scoped `context-docs` gate (record, lifecycle and continuity suites plus
diff/clean checks); the full default gate is required on the final exact head
before merge-class publication and for any tools/kernel change.

Windows path boundary: files exchanged between the Git Bash shell and Windows
Python must be addressed by Windows paths (`C:/Users/...`), never `/tmp/...`.
