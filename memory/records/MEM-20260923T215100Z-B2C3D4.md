# Instruction layers must not contradict each other

The 2026-09-23/24 state had two simultaneous instruction layers for the
same decision: the user-level AGENTS.md + PreToolUse hook forbade
`run_in_background` (mandating foreground + redirect + sleep/tail),
while the workspace router mandated the exec detour (and after v4, the
background re-call). A model obeying both wastes round-trips satisfying
one layer then the other; after the v4 flip the two layers directly
deadlocked (one demands background, one forbids it). Instruction files
and hooks are MEMORY with enforcement teeth - when two layers disagree,
every retry pays the disagreement as tokens.

Rules:

1. Before adding a mechanical instruction layer (AGENTS.md section,
   hook), SWEEP the existing layers (global, workspace, repository) for
   contradictions; resolve or supersede explicitly in the same change.
2. Layer precedence follows the platform (more-specific wins), but a
   lower layer must never silently re-implement a decision a higher
   layer owns - it references the canonical record instead.
3. When an ADR changes routing law, the batch that lands it also lands
   the instruction-layer deconfliction (all AGENTS.md sections + hook
   registrations involved) in the SAME transaction - half-flipped
   states are the hazard.
