# Subagents are router-free: hooks never fire inside child runtimes

Verified at the pinned ZCode revision and corroborated live: subagent
child `AgentRuntime`s are constructed without a hook runner, so every
PreToolUse hook - including the qiven workspace router with all its law
denials (heredoc authoring, long-class background routing, sweep
exec-lease, gate guards) - applies ONLY to main-session tool calls.
Worker tool calls run with no mechanical backstop at all.

Consequences recorded:
1. Worker-side compliance rides the brief and the ACK honesty duty;
   there is no mechanical enforcement inside subagents at this revision.
   Briefs must carry the binding prohibitions explicitly.
2. The OBL-F1A2B3 router-denial probe is redesigned (the router cannot
   be a worker's correction channel); see
   views/workflows/subagent-boundary-experiments.md §0/§2.
3. Hook-carrier coverage in qiven-docs PR #3 census reaches main-session
   entry paths only; wiring hooks into child runtimes would be a ZCode
   fork extension, an input to the harness-mediation lane.
4. Router repair batches (path-prefix escape, gate-configure wrap gap)
   remain main-session-scoped by construction.
