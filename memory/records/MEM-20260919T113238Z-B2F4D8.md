# Git account identity does not represent LLM authoring identity

After merge, the visible git author is always the machine's configured account
(`JasonHuang`), regardless of which model or role authored the work: an LLM
participant cannot create its own SSH key or GitHub identity. Branch names
expressed this identity informally and lost it at merge.

Therefore every LLM-authored commit message opens with an attribution header —
`role:` naming the authoring designation (canonical role or owner-granted
session designation) and `LLM:` naming the serving model plus its reasoning
effort — ahead of the conventional subject. The header is attribution
provenance, not an authority claim; the ADR-0035 rule-4 disclosure duty applies
to the `LLM` line, and typed handoff evidence (H1-H4) is unaffected.

Contract: `collaboration/operating-contract.md`, section "Commit identity
attribution".
