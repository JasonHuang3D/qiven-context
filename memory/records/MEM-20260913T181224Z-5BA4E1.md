# Foundation portability is defined by explicit platform boundaries and continuously verified CI targets

Foundation portable code must not accumulate unrelated OS-specific behavior, and platform-specific implementation is isolated behind explicit boundaries. Public APIs prefer platform-neutral types; process- or OS-specific types require deliberate boundary design.

At the Phase I pin, CI continuously validates Windows Server 2022 x64 with MSVC/Visual Studio 2022, Ubuntu 24.04 x64 with GCC and Clang, macOS 15 x64 and ARM64 with AppleClang, plus a Linux/Clang contract configuration with exceptions and RTTI disabled under AddressSanitizer and UndefinedBehaviorSanitizer.

Hosted-runner compiler versions are evidence for the toolchains currently exercised, not minimum-version promises. Additional ARM64 platform combinations become support contracts only when CI continuously covers them.
