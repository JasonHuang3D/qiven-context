## Interpretation and exclusions

C01-C06 are accepted as the scoped Context read-contract remediation under the
owner's authority in ADR-0032. Tests cover missing mandatory inputs, ContextView
closure, protected constraints outside Top-K, budget failure, metadata/source
fidelity, immutable Git capture, changes between selection and rendering, snapshot
reuse, payload inconsistency and unknown/negative/contradictory conditions.

Deterministic embedding/reranking doubles exercise source, candidate and evidence
contracts. This is not a fresh blind model-quality or general-recall acceptance.
No claim is made that declared constraints exhaust all natural-language duties,
or that a hash proves authenticity. Context never grants execution authorization.
Non-Git directory capture requires quiescence and is non-authoritative. Git commit
capture is the production read consistency boundary.
