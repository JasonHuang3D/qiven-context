# Context R2: C07-C08

## Scope and review result

R2 closes the remediation boundary recorded after R1.

C07 makes `collaboration/context-compiler.md` explicitly a historical Batch 003
baseline composed with the later lifecycle and R1 read contracts. It removes the
remaining ambiguity that historical v1 statements could override accepted v3
read behavior, and distinguishes conflict detection from permission to retain
resolvable competing active truth.

C08 defines `supersedes` and `superseded_by` as one reciprocal, acyclic canonical
replacement graph. It adds obligation replacement fields, schema uniqueness,
status coherence, reciprocal-edge, target-status, self-edge and cycle validation.
Three existing one-way cross-category edges are repaired by making ADR-0026 and
ADR-0027 explicitly reciprocal with the memory records that already named them as
successors.

No Context Engine storage or service architecture is selected in this batch.

## Candidate and validation

Implementation candidate `88a6fedeaf7dda8d19620a6adc9c447aa02e85b5`, tree
`6796ae2545d9e28de45114b71ca22ede77643326`, is based directly on accepted `main`

6.18.44 x86_64, with PyYAML 6.0.2, jsonschema 4.23.0, attrs 26.1.0,
referencing 0.37.0 and rpds-py 2026.6.3.

`python tools/test_all.py` passed all 11 portable suites, 126 tests, zero failures.
The Windows-only resolver suite was skipped because this batch changes no Windows
entrypoint or resolver behavior. `git diff --check HEAD^ HEAD` passed and the
candidate working tree was clean.

Before the candidate commit, the full runner correctly rejected the dirty working
tree under R1's immutable snapshot contract. That run did not reach the affected
suite assertions and is not an implementation failure. An earlier direct validator
launch also stopped before collection because the ambient interpreter lacked
`jsonschema`; the isolated environment above resolved that runtime prerequisite
without changing the candidate.

## Acceptance interpretation

The tests prove the documented structural lifecycle invariants and preserve the
existing retrieval/read contracts. They do not prove natural-language truth,
ranking quality, or an unimplemented database/service architecture. Portable
validation authority is ADR-0032 and `collaboration/context-validation.md`.

The closeout delta after the validated candidate is restricted to this audit,
compact current state and the existing Qiven-v7 checkpoint. Final publication
requires exact remote review, repository validation of that closeout, and an exact
tree/ref check.
