# Standardize collision-resistant canonical ID issuance before automating record creation

Current IDs satisfy the schema and validator, but the initial seed set included visibly hand-chosen suffixes. That is acceptable for a tiny curated bootstrap; it is not a sound issuance strategy for automated ingestion.

The future mechanism should keep IDs stable, human-copyable, and repository-wide unique without introducing a central database as canonical state. The exact algorithm is intentionally not chosen by Genesis Import.
