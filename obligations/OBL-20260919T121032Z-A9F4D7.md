# Improve Qiven Operator CLI ergonomics and machine-output shape

Upstream Devkit work, per semantic ownership: Devkit owns the orchestration
mechanism, repositories own declarative task/policy metadata. Four improvements
constitute completion:

1. `gate [name]` — optional positional gate name, defaulting to the repository
   default gate; unknown names list available gates.
2. Subcommand-level usage errors print the subcommand's own usage, not only the
   top-level summary.
3. `--json` writes buffered suite logs to a durable output file and prints a
   compact machine summary (task, status, duration, log path) instead of one
   unbounded line.
4. Operator snapshot roll into managed repositories, gate-green.

Progress 2026-09-19: the four improvements are implemented in
`JasonHuang3D/qiven-devkit` (branch `jason-extended-cognition/operator-ergonomics`,
commit `edf4b9686a` after the attribution-format rewrite
(`MEM-20260919T135930Z-F1C2A9`); originally `65e4871`); the operator snapshot
is rolled into qiven-context and qiven-context-draft (the context copy was a
pre-0.1.4 snapshot lacking `{python}` placeholder support — upgrading, not
drifting). The qiven-foundation and qiven-math rolls remain and complete this
obligation.
