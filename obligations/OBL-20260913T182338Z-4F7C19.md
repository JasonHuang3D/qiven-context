# Reconcile Foundation managed-file drift semantically before Devkit adoption

The historical rehearsal established that Foundation is not a clean exact match for the Devkit managed snapshot. That is not permission to let Devkit win automatically.

The thirteen divergent managed paths must be reviewed semantically before real adoption. This Genesis record deliberately does not invent their individual contents because the exact per-path drift report is not available in the current evidence set.
