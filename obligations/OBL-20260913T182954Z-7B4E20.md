# Resume Math Batch 008 vector algorithms after qiven-context cold-boot acceptance

The preserved candidate scope was re-confirmed and implemented as:

- `dot` for `Vec2`, `Vec3`, and `Vec4`;
- `cross` for `Vec3` using the standard right-hand rule;
- direct algebraic `length_squared`;
- robust max-component-scaled `length`;
- `normalize` with finite, non-zero programmer preconditions;
- checked `try_normalize` returning false for zero/non-finite input and leaving the output unchanged on failure;
- `distance`;
- explicit finite non-negative componentwise absolute-tolerance `is_near` with no global epsilon or implicit relative tolerance.

Pure algebraic operations remain `constexpr` where C++20 permits; square-root-dependent operations remain runtime operations. Fast-math is outside the contract.
