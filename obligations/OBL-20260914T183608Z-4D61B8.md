# Accept the local Chat-mode Qiven Context runtime transport before production lease use

The research phase established a practical normal-Chat execution transport, but production use is still blocked on one end-to-end acceptance chain.

Required acceptance sequence:

1. intentionally synchronize `D:\JasonWork\qiven-context` to the accepted Qiven Context head;
2. keep the source clean and record the exact local Git ref;
3. explicitly invoke `@qiven` in a fresh normal Chat;
4. require the Skill to use Remote Desktop Commander on the authorized JasonPC;
5. perform exactly one coarse-grained local preflight/prepare call;
6. require a fresh machine-readable result and validate its marker/lease, exact canonical ref, source-clean state, and provenance;
7. demonstrate fail-closed behavior when the local runtime path is unavailable or invalid;
8. only then replace the diagnostic preflight with the canonical retrieval runtime and use its Context Lease for Qiven reasoning.

Serial invocation is the Phase 1 operating assumption. Concurrent Qiven cognition turns remain outside acceptance until measured independently.
