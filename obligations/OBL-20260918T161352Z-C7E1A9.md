# Upgrade chatgpt-jason view to schema v2 with historical role-model bindings

ADR-0035 made role-model bindings a first-class ContextView dimension, and
`views/zcode-jason.yaml` demonstrates the schema-v2 shape. `chatgpt-jason.yaml`
deliberately remains at schema v1 so the accepted two-layer transaction stayed
semantically frozen for the existing ChatGPT collaboration. This obligation
records the remaining work so the upgrade cannot be forgotten: the next
substantive touch of the ChatGPT view — or the next active ChatGPT+Jason
session — must declare its bindings explicitly, because an undeclared binding
is an undisclosed model identity under ADR-0035 rule 4.

The upgrade must not change chatgpt-jason semantics, workflow references, or
governance; it only makes the historical participant bindings (and their
qualification evidence, which may require reconstructing model identity from
recorded sessions) explicit under the same schema the ZCode view uses.
