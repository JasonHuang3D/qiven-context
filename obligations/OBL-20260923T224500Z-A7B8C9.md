# Hook-router segment anchor: tolerate leading whitespace

The `^`-anchored segment patterns in `hook_exec_router.py` misclassified
any segment that follows `&&`/`;` because the split leaves it a leading
space: a perfectly-formed sanctioned exec wrapper in the second position
denied as raw long-class. **Closed 2026-09-23**: segments are lstripped
before classification, the router test table carries chained-exec
regression rows, and the long-command registry records the tolerance
(devkit PR #27, merge `d1d2a3a`).
